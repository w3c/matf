### Excluded from scope

The following are out of scope for this document.
WCAG2Mobile does not:

- name every operating system to which the guidance may apply; the guidance is written primarily with Android and iOS/iPadOS in mind, which account for the large majority of mobile interactions
- include guidance for other types of mobile devices such as wearables and laptops; it provides guidance specifically for mobile applications on phones and tablets 
- propose changes to WCAG 2 or its supporting documents, or include interpretations for implementing WCAG 2 in web technologies
- provide sufficient guidance on its own to ensure accessibility in mobile applications — as a web standard, WCAG does not fully cover all accessibility requirements for non-user interface aspects of platform software, user interface components as individual items, or closed functionality (where there is no assistive technology to communicate programmatic information)
- comment on hardware aspects of products, because the basic constructs on which WCAG 2 is built do not apply to these
- comment on WCAG Level AAA success criteria
- provide supporting techniques for implementing WCAG 2 in mobile applications
- describe how mobile applications should conform to it; it is purely an informative note about mobile applications, not a standard
